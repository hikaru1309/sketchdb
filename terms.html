利用規約

この利用規約（以下「本規約」）は、SketchDB（以下「本サービス」）の利用条件を定めるものです。 本サービスを利用した時点で、本規約に同意したものとみなします。

1. 本サービスについて

  1. 本サービスは、CREATE TABLE 文などのSQLからER図やテーブル定義書を作成する無料のWebツールです。
  2. 本サービスは試験提供（Beta）中です。運営者は、予告なく本サービスの内容を変更し、または提供を中断・終了することがあります。

2. 禁止事項

本サービスの利用にあたり、次の行為を禁止します。

  1. 法令または公序良俗に反する行為
  2. 本サービスや、本サービスを配信するサーバーに過度な負荷をかけるなど、運営を妨げる行為
  3. 本サービスを、運営者や第三者が提供するものであるかのように偽る行為
  4. 第三者の権利や利益を侵害する行為

3. 作成した図・定義書について

本サービスで作成した図や定義書（PNG・SVG・Markdown・CSV など）の権利は、入力したSQLの権利者に帰属します。 運営者は権利を主張しません。設計書や資料などに自由にお使いください。

4. 免責事項

  1. 本サービスは現状のまま提供されます。運営者は、作成される図の正確性・完全性、特定の目的への適合性、 不具合がないことなどを保証しません。SQLの書き方によっては、テーブルやリレーションを正しく読み取れない場合があります。 重要な用途では、元のSQLと照らし合わせて確認してください。
  2. 本サービスの利用、または利用できなかったことにより利用者に生じた損害について、運営者は責任を負いません。 ただし、運営者の故意または重大な過失による場合は、この限りではありません。

5. 本規約の変更

運営者は、必要に応じて本規約を変更することがあります。変更後の本規約は、このページに掲載した時点から効力を生じます。

6. 準拠法

本規約は日本法に従って解釈されます。

プライバシーポリシー

1. 入力したSQLについて

  1. 入力したSQLの解析と図の作成は、すべてお使いのブラウザの中で行い、運営者や第三者に送信することはありません。
  2. さらに、ブラウザのセキュリティ機能（Content-Security-Policy）により、本サービスのページの中のプログラムが外部と通信すること（fetch や外部の画像・スクリプトの読み込みなど）を禁止しています。
  3. 次に開いたときのために、入力したSQL・テーブルの位置・表示の設定を、お使いのブラウザの中（localStorage）に保存します。 この情報は外部に送信されず、運営者も見ることはできません。 消したいときは、ツール画面のゴミ箱ボタンを使うか、ブラウザの設定でこのサイトのデータを削除してください。
  4. 「URLで共有」を使うと、入力したSQL・入力フォーマット・テーブルの位置を圧縮して、リンクのURLの「#」より後ろに入れます。 「#」より後ろはブラウザからサーバーへ送られないため、リンクを開いても運営者や配信元（GitHub）にSQLが届くことはありません。 ただし、リンクを受け取った人はSQLを見られます。社外秘のSQLを共有するときは、渡す相手と渡し方（チャットやメールの保存先など）に気をつけてください。

2. アクセス解析について

本サービスは、現在アクセス解析ツールや Cookie を使用していません。 なお、本サービスは GitHub Pages で配信しているため、配信の仕組みとして、GitHub がアクセスの記録（IPアドレスなど）を取得する場合があります。 詳しくは GitHub のプライバシーに関する声明をご覧ください。

3. ご意見・不具合の報告フォームについて

  1. 「ご意見・不具合の報告」は Google フォームを使用しています。送信された内容は Google のサービスに保存されます （Google のプライバシーポリシー）。
  2. 送信された内容と、任意で入力された連絡先は、お問い合わせへの返信と、本サービスの改善のためにのみ使用します。 法令に基づく場合を除き、本人の同意なく第三者に提供することはありません。
  3. 送信した内容の削除を希望する場合は、同じフォームからご連絡ください。
  4. フォームにSQLを含める場合は、社外秘の情報を含めないでください。

4. 本ポリシーの変更

運営者は、必要に応じて本ポリシーを変更することがあります。変更後の本ポリシーは、このページに掲載した時点から効力を生じます。

5. お問い合わせ

本規約・本ポリシーに関するお問い合わせは、 ご意見・不具合の報告フォーム からお願いします。
