SketchDB Beta ツールを開く

CREATE TABLE文を貼るだけで、ER図を作成

SketchDBは、データベースのテーブル定義（CREATE TABLE文）からER図を作る無料のWebツールです。 登録は不要で、SQLは外部に送信されません。

無料で使ってみる

できること

  • 貼るだけでER図に

    CREATE TABLE文を貼ると、その場でテーブルとリレーション（外部キーのつながり）を図にします。書いている途中でも図が更新されます。

  • ダンプの出力もそのまま

    MySQL・PostgreSQL・MariaDB・SQL Server・SQLite に対応（自動判定）。mysqldump・pg_dump・SQLite の .dump・SQL Server Management Studio のスクリプトの出力なども、余計な部分を消さずにそのまま貼れます。

  • COMMENTを論理名で表示

    カラムやテーブルの COMMENT を「論理名」として表示できます。「user_id」ではなく「会員ID」のように、日本語の名前で図を作れます。

  • テーブル定義書

    テーブルごとのカラム一覧（論理名・物理名・型・主キー・外部キー・NOT NULL・デフォルト値）を表示し、書式付きの Excel（表紙・テーブル一覧・テーブルごとのシート）、Markdown・CSV・PDF で保存できます。

  • テンプレート

    ECサイト・SaaS基盤・ブログ・予約システム・社員と勤怠のサンプルを用意しています。手元にSQLがなくても、すぐに試せます。

  • 画像や Mermaid で保存

    PNG（資料やスライド向け）と SVG（拡大してもぼやけない）で保存できます。Mermaid でコピーすれば、GitHub の README や Qiita にそのまま図として貼れます。テーブルの位置はドラッグで調整できます。

  • SQLは外部に送信されない

    解析はすべてブラウザの中で行います。社内のテーブル定義でも、サーバーに送られる心配はありません。

  • 画面でテーブルを編集

    「＋ テーブル」で新しいテーブルを作ったり、図のテーブルをダブルクリックして列を足したりできます。テーブルの右端の ○ から別のテーブルへ線を引くと、外部キーも作れます。左のSQLは、編集したテーブルの部分だけが書き換わり、AUTO_INCREMENT や索引などの書き方も残ります。元に戻す・やり直しもできます。

  • ダークモード・スマホ対応

    明るい配色と暗い配色を切り替えられます。スマホでも図を確認できます。

使い方

  1. 1左の欄に CREATE TABLE 文を貼り付ける
  2. 2右側にER図ができる。テーブルはドラッグで動かせて、ダブルクリックで編集もできる
  3. 3「保存」から PNG / SVG で保存、または Mermaid でコピーする

よくある質問

無料で使えますか？

はい、無料で使えます。会員登録も不要です。

貼り付けたSQLはどこかに送信されますか？

送信されません。SQLの解析と図の作成は、すべてお使いのブラウザの中で行います。 さらに、ブラウザのセキュリティ機能（Content-Security-Policy）で、ページの中のプログラムが外部と通信すること（fetch や外部の画像・スクリプトの読み込みなど）を禁止しています。 次に開いたときのために、SQLとテーブルの位置をこのブラウザの中（localStorage）に保存しますが、外部には送りません。

どのSQLに対応していますか？

MySQL・PostgreSQL・MariaDB・SQL Server・SQLite の CREATE TABLE、ALTER TABLE（外部キー・主キーの追加）、COMMENT ON、SQL Server の説明（MS_Description）に対応しています。 INSERT や SET などER図に関係ない文は読み飛ばすので、ダンプの出力もそのまま貼れます。 Prisma Schema などへの対応も予定しています。

作った図は仕事で使ってもいいですか？

はい。保存した画像は、設計書や資料などに自由に使えます。

読めないSQLがありました

お手数ですが、ご意見・不具合の報告 から教えてください。読めなかった部分を教えていただけると、対応の参考になります。
